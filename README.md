# AWS Cloud Resume Challenge

This is my attempt at cloud resume challenge in AWS.
What is Cloud Resume Challenge? - (https://www.youtube.com/watch?v=rzdSuiU_TQc&list=PLK_LRl1CH4L_ko1-Xm04ATPTduu6gaSM8&index=6) is a multiple-step resume project which helps build and demonstrate skills fundamental to pursuing a career in Cloud. The project was published by Ryan Whitfield.
